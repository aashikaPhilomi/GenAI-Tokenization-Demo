# GenAI Tokenization Demo

This project demonstrates the basic tokenization process used in Large Language Models (LLMs).

## Concepts Demonstrated

- Original Text
- Tokenization
- Tokens
- Token IDs
- Encoding
- Attention Mask
- Decoding

## Workflow

Text
↓
Tokenizer
↓
Tokens
↓
Token IDs
↓
Encoded Output
↓
Decoded Text

## Technologies Used

- Python
- Hugging Face Transformers
- GPT-2 Tokenizer

## Example

Input:

Hello, how are you doing today?

The program converts the input text into:

- Tokens
- Token IDs
- Encoded representation

Finally, it decodes the token IDs back into readable text.
